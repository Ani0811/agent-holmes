## 4. Sandboxed Execution & Untrusted Code Warning

Agent Holmes clones repositories into isolated local workspace directories (`./workspaces/case_<id>/`) and executes build and test commands via subprocesses.

1. **Untrusted Repositories:**  
   Executing automated tests (`npm test`, `pytest`, etc.) inherently runs arbitrary code defined in the target repository's build configurations (`package.json`, `setup.py`, Makefile, etc.).
2. **User Precaution:**  
   You should exercise caution when pointing Agent Holmes at untrusted third-party repositories. For high-risk or unvetted codebases, we strongly recommend running Agent Holmes inside containerized Docker environments or dedicated virtual machines with restricted network and filesystem permissions.
